# Generated PW-0001 media

These tiny fixtures were generated locally with FFmpeg from synthetic color and
sine-wave sources. They contain no third-party or private media and are released
under CC0-1.0 for redistribution with this repository.

- `red.png`: solid red 64×64 image.
- `blue.png`: solid blue 64×64 image.
- `tone.wav`: one second, 440 Hz, mono PCM16 at 16 kHz.
- `red-then-blue.mp4`: two-second 64×64 H.264 video, red then blue.

The committed bytes, rather than regeneration, define fixture identity.
